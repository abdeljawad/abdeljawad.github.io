# Ahmed Abdeljawad — portable static website

This project contains the complete static source for the website.

- Internal pages and images use relative paths.
- There are no hard-coded references to the hosting domain.
- The site can be moved to another host/domain without changing HTML paths.
- The light/dark theme follows the operating system by default and remembers a manual choice across pages.
- Roboto is loaded from Google Fonts to preserve the typography of the current site. External academic/profile links intentionally remain external.

Open `index.html` directly for a local preview, or deploy the folder as-is.
